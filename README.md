# Grand Prix Performance Intelligence

A Formula 1 analytics portfolio project focused on driver and constructor performance across seasons.

## Tools
- Power Query for data cleaning and transformation
- Power BI and DAX for analytical measures and reporting
- Python and Pandas for data validation and analysis

## Project Contents
The complete project files, datasets, measures, documentation, and analysis are available in the project folder below.

[Open the complete project and documentation](Grand_Prix_Performance_Intelligence/README.md)

## Key Areas
- Driver and constructor performance
- Race wins and championship trends
- Data quality and missing-value handling
- DNF analysis and KPI validation
- Analytical documentation and business questions
