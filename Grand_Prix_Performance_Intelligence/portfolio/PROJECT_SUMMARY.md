# Project Summary

**Project:** Grand Prix Performance Intelligence  
**Domain:** Sports analytics  
**Tools:** Power BI, Power Query M, DAX, Python/pandas  
**Source:** F1DB — Open Source Formula 1 Database (CC BY 4.0)  
**Project owner:** Abdulaziz Salem

## Summary

I used historical Formula 1 data to compare driver and constructor performance across seasons. The work included cleaning and profiling 12 CSV tables, setting up the model, writing measures, and checking selected results against the source files.

## What the project covers

- Wins, points, podiums and constructor win share
- Change in starting position versus finishing position
- DNF and other non-classified outcomes
- Driver and constructor trends by season
- Circuit locations and Grand Prix history
- Pit-stop and qualifying data where the source has coverage

## One useful finding

Red Bull won 21 of 22 race events in the 2023 data, a 95.45% win share. The project also highlights that a blank finish position is not the same as a literal `DNF` source status.

## What is in the repository

Source CSVs, Power Query snippets, DAX definitions, model documentation, audit outputs, tests, Power BI working screenshots, and copy for a CV and LinkedIn post. The `.pbix` binary is not included in this repository.
